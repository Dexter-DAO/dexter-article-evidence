## Verification

Article guides link each claim to specific records and source. Each collection includes verification commands, dependency versions, file hashes and the scope of its checks. Downloadable packages let a reader inspect the material when a live page or RPC endpoint is unavailable.

The [article catalog](articles/index.json) provides a machine-readable starting point. Evidence manifests identify exact source revisions; release archives preserve the files used for each publication. Source licenses and notices remain with their collections.
